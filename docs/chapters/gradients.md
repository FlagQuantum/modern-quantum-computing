# Parameterized circuits and gradients

**Starter draft · FlagQuantum 0.3.1 · CPU · complex128**

Read [measurement](measurement.md) first. For the same state, define $f(\phi)=\langle Z\rangle=\cos\phi$. Ordinary calculus gives $f'(\phi)=-\sin\phi$.

For this rotation, the parameter-shift identity follows directly from the cosine addition formulas:

$$
f'(\phi)=\frac{f(\phi+\pi/2)-f(\phi-\pi/2)}{2}=-\sin\phi.
$$

| Mathematical operation | Implementation in `examples/gradients.py` |
|---|---|
| Trainable scalar $\phi$ | `torch.tensor(0.6, dtype=torch.float64, requires_grad=True)` |
| $f(\phi)$ | `expectation(phi)` builds and executes a fresh circuit |
| Differentiate $f$ | `torch.autograd.grad(value, phi)` |
| Analytic reference $-\sin\phi$ | `-torch.sin(phi)` |
| Parameter-shift reference | `(expectation(phi+torch.pi/2)-expectation(phi-torch.pi/2))/2` |
| Central difference | `(expectation(phi+1e-5)-expectation(phi-1e-5))/(2e-5)` |

The circuit uses tensor angles directly so its output remains connected to PyTorch autograd. Calling `.item()` before constructing a gate would detach the angle.

## Run and verify

```bash
python examples/gradients.py
```

Expected output:

```text
<Z> = 0.825335615
d<Z>/dphi = -0.564642473
Autograd, analytic, parameter-shift, and finite-difference gradients agree.
```

[Read the complete program](https://github.com/FlagQuantum/modern-quantum-computing/blob/main/examples/gradients.py). The central difference uses a looser tolerance because it has truncation and rounding error.

## Exercises and limits

1. Replace the angle by `2*phi`. Derive the additional chain-rule factor.
2. Define $L=(f(\phi)-0.2)^2$ and derive its derivative before using an optimizer.
3. Vary the finite-difference step. Explain why a smaller step is not always more accurate.

This shift rule assumes a gate generated by a Pauli operator divided by two, used once with the parameter. Shared parameters and other generator spectra require a new derivation. The [VQE chapter](vqe.md) demonstrates a different normalization.
