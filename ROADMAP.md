# Roadmap

- [x] Publish an English [six-part, 28-chapter plan](docs/contents.md) and [detailed chapter specifications](docs/book-plan.md).
- [x] Establish conventions, a chapter template and reference reading paths.
- [x] Add executable measurement, gradients and hydrogen VQE starters.
- [x] Add example CI, strict web builds and a LaTeX PDF sample pipeline.
- [x] Publish a versioned sample and the GitHub Pages web edition.
- [ ] Review the plan and sample chapters with target readers.

## Phase 2: build a continuous learning path

Write Chapters 1–4, then expand 5–6. Develop 12–14 and 16, then 25–27. This connects the mathematical foundations to circuit models, derivatives, optimization and a complete paper-reproduction workflow. The three existing starters are pilots for Chapters 5, 13 and 27, not completed final chapters.

## Phase 3: complete algorithms and supported extensions

Complete Chapters 7–11, then applications and extensions in 15 and 17–24. Develop the independent QAOA project in Chapter 28. Select dedicated primary references and verify supported software paths before implementing specialized simulation or platform chapters.

## Phase 4: review a full scholarly edition

Run independent mathematical and reader reviews, check every example and both reading formats, complete exercises and attribution, then freeze a coherent manuscript and its code revision. PDF samples and the live website do not by themselves establish readiness for arXiv submission. Choose a custom domain separately; the current web edition uses GitHub Pages.

The detailed plan defines prerequisites, learning outcomes and acceptance gates. Progress depends on correctness and readability rather than a release-date commitment.
