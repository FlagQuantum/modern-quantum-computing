# Roadmap

## Phase 1: prove the teaching format

- [x] Establish an English book structure, conventions and chapter template.
- [x] Add executable measurement, gradients and hydrogen VQE starters.
- [x] Add example CI and a strict documentation build.
- [ ] Review sample chapters with readers who know Python but are new to quantum computing.
- [ ] Add foundations needed to read the samples without outside prerequisites.
- [ ] Publish a first numbered draft after independent editorial review.

## Phase 2: build a coherent course

Complete foundations, algorithm chapters, optimization and hybrid models. Add exercises of increasing difficulty and carefully scoped solutions. Expand simulation and noise chapters only with executable evidence.

## Phase 3: publish and teach

The first three-chapter PDF sample pipeline is available. Expand the print edition, add ebook output, course material and more paper reproductions. Choose a custom domain and a versioned publication policy. A deployment workflow is provided, but a production domain is not configured.

Progress depends on correctness, readability and reader feedback. This roadmap is not a release-date commitment.
